API から一括エクスポート

Tripo API で生成したモデルを全部、表示中のフォルダにダウンロードします。保存済みのものはスキップするので、途中で止まっても再実行すれば続きから始まります。Studio（Web版）で作ったモデルは対象外です。

GLB はそのままダウンロードするのでクレジットを使いません。

軽量化

軽くしたコピー（名前_lite.glb）を別に作ります。元のファイルはそのままです。

ポリゴンは形が崩れすぎないところで止まるので、指定より少し多めに残ることがあります。

ダウンロードから取り込む

Tripo Studio（Web 版）などで保存したモデルを、ダウンロードフォルダから表示中のフォルダにコピーします。zip はフォルダに展開します（FBX・OBJ のテクスチャもそのまま入ります）。

設定

API キーは platform.tripo3d.ai で作れます。Windows の資格情報マネージャーに保存され、このPCの外には送られません（Tripo API への通信を除く）。Studio のクレジットとは別に、API 用のクレジットが必要です。
